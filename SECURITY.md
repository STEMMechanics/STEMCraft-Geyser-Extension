# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public issues, discussions or
pull requests.

Instead:

- [Report the vulnerability privately through GitHub](https://github.com/STEMMechanics/STEMCraft-Geyser-Extension/security/advisories/new), or
- Email [hello@stemmechanics.com.au](mailto:hello@stemmechanics.com.au).

Include the affected extension and Geyser versions, reproduction steps,
potential impact and any suggested mitigation. Confirmed issues will be handled
before public disclosure where practical.

## Supported versions

Security fixes target the latest released version. Users should keep Geyser and
this extension current.
